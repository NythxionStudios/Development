Nythxion Watermarker

Protect. Identify. Verify.

Desktop software for watermarking images and videos, identifying your work, and verifying it later. It runs locally on your computer.

Download for Windows Release notes

Setup 1.2.0 · about 237 MB · Windows 10 or later

Platform
Windows
Technology
Node.js, Electron
Version
v1.2.0
Released
Sep 28, 2026
License
Proprietary

Features

  • Visible watermarks for images
  • Video watermarking, exported at the original resolution and frame rate
  • Holographic watermark embedding
  • Unique watermark IDs
  • Metadata embedding and verification for images and videos
  • Artwork Archive: a local record of watermarked work with IDs, dates, and verification status
  • Saves: reusable watermark configurations
  • AI Instruction: an extra layer intended to discourage AI tools from removing a watermark
  • Alpha fingerprinting
  • Figma integration, with Figma metadata support

System requirements

  • Windows 10 or later
  • 64-bit processor
  • 4 GB RAM or more
  • About 500 MB of free storage

Installation

  1. Run the Nythxion Watermarker Setup installer.
  2. Choose an installation folder if you want a different location.
  3. Complete the installation.
  4. Launch Nythxion Watermarker from the shortcut it creates.
  5. The installer also provides a standard Windows uninstall option.

Good to know

  • AI Instruction does not guarantee protection. Advanced tools can still remove or change a watermark.
  • Applying a new watermark to an image that is already watermarked may invalidate or overwrite the existing one.
  • The Artwork Archive and saved configurations stay on your computer.

Nythxion Shortcuts

Press. Open. Done.

A Windows utility for opening apps and websites with keyboard shortcuts. Shortcuts keep working while the app runs in the background.

Features

  • Global keyboard shortcuts that work while the app runs in the background
  • Website shortcuts, with addresses completed automatically (youtube.com becomes https://youtube.com)
  • Application shortcuts, with an app finder so you don't need to type file paths
  • Restores or focuses an application window that is already open
  • Custom shortcut configuration
  • Light, purple, and dark themes
  • UI sound toggle
  • Custom Nythxion interface with custom popups

These are examples. You can change any of them.

System requirements

  • Windows 10 or later
  • 64-bit processor
  • 4 GB RAM or more
  • About 200 MB of free storage

Installation

  1. Run the Nythxion Shortcuts Setup installer.
  2. Choose an installation folder if you want a different location.
  3. Complete the installation.
  4. Launch Nythxion Shortcuts from the shortcut it creates.
  5. The installer also provides a standard Windows uninstall option.

Good to know

  • Normal use does not require administrator privileges.
  • Shortcut configurations and settings are stored locally and persist between sessions.

Nythxion Sort

A small, dependency-free browser game that turns sorting algorithms into hands-on puzzles.

Play in your browser View source on GitHub
Platform
Web browser
Technology
HTML, CSS, JavaScript
License
MIT
Build step
None

Features

  • Game Mode for Merge Sort and Quick Sort, with 8 to 64 bars
  • Scoring with combos for correct moves
  • Optional sound effects that you can mute
  • Visualizer Mode for Merge Sort and Quick Sort, with 8 to 256 bars
  • Compare mode runs both algorithms on the same starting array
  • Adjustable step timing, pause and resume, and single-step playback
  • Short explanations of each algorithm
  • Restart the same array, or shuffle for a new one

Run it yourself

  1. Clone the repository from GitHub.
  2. Open index.html in a modern browser.
  3. No build step, package installation, or backend is required.
